# Inventario

 ## Acerca del proyecto
 * Registro de productos.
 * Consulta de productos

 ## Tecnología a usar
 * php v8.3.30 
 * HTML 5
 * CSS 3
 * HeidiSQL v12.17.0.7270

 * Laragon v8.6.1 
 * VSCode v18.5.1
 * Extensión (de php, css, html)
 * Navegador

 ## Configuración e instalación
 1. Encender servidores de Apache y MySQL
 2. Ejecutar script de la base de datos
 3. Cambiar el usuario y contraseña en el archivo de conexión en la carpeta config por las credenciales propias
 4. Crear el proyecto en c:/laragon/www/
 5. Acceder al proyecto con la ruta localhost/inventario
